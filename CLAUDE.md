# Aim
This projects aims at creating a map of selected resources relative to the city of Baku, Azerbaijan. The project should load data points from .csv files so that it will be easier to update. 

# Output
The map should be very usable on mobile phones. 

## New data
User that receive an invite via link can add and comment on locations

## Search
Aside the page with the map, there should be a listing of all the pinned venues with the possiblity of quickly searching
